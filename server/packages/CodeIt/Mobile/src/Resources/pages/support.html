Support: code it CRM app

The internal app of the code it team, connected to the company's CRM. For help, write to support@coditvision.com; we usually answer within one working day.

Can't sign in? Use the same e-mail and password as the web CRM (crm.coditvision.com). No notifications? Allow notifications for the app in the phone's settings, then sign out and in again. Each person sees only what their role allows. Privacy policy.
